Working glossary

Deterministic calculation
The same valid inputs and rules produce the same result. Use explicit calculations for totals and reconciliation.
Reconciliation
Checking that records, categories, and totals agree across sources and explaining any differences.
Grounding
Connecting an answer to relevant source material. Retrieved text can still be wrong, outdated, or insufficient.
RAG
Retrieval-augmented generation: retrieving source passages and supplying them as context for an answer.
Authorization
Checking whether a person or system may access a record or perform an action. Retrieval must respect these permissions.
Abstention
Withholding an answer or action when evidence or authorization is insufficient, with an appropriate next step.
Prompt injection
Untrusted content that tries to redirect a model's behavior. Treat retrieved text and tool results as data, not authority.
Idempotency
Designing an operation so repeating the same request does not create additional unintended effects, such as duplicate tickets.
Evaluation set
A collection of cases and expected outcomes used to assess behavior. Include realistic examples and consequential failures.
False negative
A missed positive case, such as an urgent message classified as routine. Its cost depends on the task.
Regression test
A repeatable check that previously working behavior remains correct after a change.
Human approval gate
A defined pause before an action proceeds, with a named approver, evidence, and approval criteria.
Least privilege
Granting only the access required for a specific task, with limits appropriate to the action.
Baseline
A measured description of current performance used for comparison with a proposed change.
