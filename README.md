# Applied AI Lab — public portfolio homepage

A standalone static homepage intended for free hosting on GitHub Pages or Cloudflare Pages.

## Publish with GitHub Pages
1. Create a public GitHub repository (for example `applied-ai-lab`).
2. Upload `index.html` to the repository root.
3. Under Settings → Pages, choose Deploy from a branch, `main`, root (`/`).
4. Wait for GitHub to show the published URL; open it and test both desktop and mobile.

## Studio link
The Studio card deliberately displays “Public demonstration coming soon.” Do not link to the private Apps Script pilot or publish private reporting credentials. Once a separate public Studio demo is verified, replace that text with an anchor to its verified URL.

## Portability
This is a single-file static site. It can be moved to another host or integrated into a personal portfolio without changing the course deployments.

## Scope
The existing Foundations website is linked but not modified. Studio and reporting backends are not deployed by this package.
